# Store-ийн metadata ноорог

App Store ба Google Play-д гаргах үеийн бичвэрийн ноорог (FR-17.3). Гол түгээлт нь PWA тул
энэ гаргалтад store-д илгээхгүй: Apple Developer Program (GAP-02) ба Google Play Console (GAP-03)
бүртгэлгүй. Бүртгэл үүссэн өдөр эндээс хуулж оруулна; илгээх команд `docs/RELEASE.md`-д.

| Файл | Агуулга |
|---|---|
| `metadata.mn.md` | Монгол: нэр, дэд гарчиг, богино ба урт тайлбар, түлхүүр үг, шинэчлэлийн тэмдэглэл |
| `metadata.en.md` | Англи: ижил бүтэц (шууд орчуулга биш, утгаар) |
| `review-notes.md` | Шалгагчид зориулсан тэмдэглэл, насны ангилал, өгөгдлийн аюулгүй байдлын маягт, зөвшөөрлүүд |

Бичих дүрэм (`mobile/src/platform/__tests__/policy-guards.test.ts` шалгана):

- Апп хийдэггүй зүйлийг мэдэгдэхгүй. Хоёр төгсгөлийн шифрлэлтийн тухай нэг ч үг бичихгүй (§2-7).
- Харилцааг үнэлэх, оноо өгөх, тасралтгүй өдрийн тоогоор шахах бичвэр хэрэглэхгүй (зарчим 6).
- Брэнд, зохиогчийн эрхтэй дүр нэрлэхгүй (AC-AS-03).

## Дэлгэцийн зураг

Утас 6.9" (1320×2868) ба 6.5" (1242×2688), Android утас 1080×1920; таблет сонголттой.
Дараах дэлгэцүүдийг бараан theme-ээр, хуурамч хувийн өгөгдөлгүй тестийн хосоор авна:
S-20 нүүр · S-30 дурсамж · S-40 чат · S-50 төлөвлөгөө · S-60 хамтдаа · S-67 захидал нээх.

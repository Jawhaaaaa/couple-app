# Гараар шалгах жагсаалт (DEV_APPROVE)

Spec-ийн шалгах арга нь «ГАР» агуулсан AC бүр энд нэг мөртэй (шаардлага §8.5, AC-149).
`mobile/src/__tests__/manual-test.test.ts` нь Spec-ийн жагсаалттай тулгаж, дутуу AC байвал унана.
Автоматаар шалгагддаг хэсэг (E2E, IT, UT) нь тухайн тестүүдэд; энд зөвхөн бодит төхөөрөмж,
хүний нүд шаардсан хэсэг.

## Бэлтгэл

- DEV стек: `docker compose up -d` (backend, postgres, seaweedfs, mailpit, mobile-web). Имэйлийн кодыг
  Mailpit-ээс (`http://<LAN_IP>:8025`) уншина.
- Утас DEV машинтай нэг Wi-Fi-д (GAP-10). Татах хуудас S-99: `DEPLOYED.md`-д заасан хаяг.
- Хоёр акаунт: **A** (Android утас) ба **B** (iPhone). Тэмдэглэгээ: ✅ тэнцсэн · ❌ унасан (дэлгэцийн зураг хавсаргана).
- Prod HTTPS шаардсан мөр (AC-06 утас, AC-51, AC-159) нь Oracle-д байршуулсны дараа (GAP-11).

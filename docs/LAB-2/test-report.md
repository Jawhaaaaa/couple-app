### 3.1 Гэрээний нийцэл (согог 1, 2) — deployed API

Скрипт: `contract_check.py`. Гурван хэрэглэгч бүртгэж, хоёрыг нь хос болгосон. Дараа нь бүртгэл → хос холбох → нүүр → асуулт → зүрх → upload → дурсамж → чат → болзоо → ой → жагсаалт → зорилго → захидал → capsule → check-in → мэдэгдэл → хос тусгаарлалтын урсгалаар 138 хүсэлт илгээсэн. Хариу бүрийг `contracts/openapi.yaml` (3.1)-ийн тухайн operation ба статусын schema-тай JSON Schema 2020-12-оор тулгасан. Мөн статус гэрээнд зарлагдсан эсэхийг шалгасан.

**Үр дүн: 138/138 давсан.**

Required биш талбарт `null` бичигдсэн тохиолдол нэг ч алга (schema зөрчил 0).
- Согог 2a: `.jpg` нэртэй HTML-ийн эхний chunk → 415. Дараагийн `complete` → **415** `MEDIA_TYPE_FORBIDDEN` (өмнө нь 410), дахин илгээсэн chunk → 415. Цуцалсан upload-ийн `complete` ба chunk → **404**. Бүгд гэрээнд зарлагдсан.
- Согог 2b: `GET /letters` (`box`-гүй) → **200**, inbox-ийн жагсаалт.
- Алдааны хариу (`ApiError` — 400 `VALIDATION_FAILED`, 401 `TOKEN_INVALID`, 401 `AUTH_INVALID_CREDENTIALS`) нь `always` тохиргооны дараа ч `null` талбаргүй.

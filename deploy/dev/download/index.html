Android — APK

APK татах ({{APK_SIZE}})

  1. Утасны камераар QR уншуулах эсвэл дээрх товчийг дарна.
  2. Татаж дуусмагц файлыг нээнэ. «Тодорхойгүй эх сурвалжаас суулгах»-ыг Chrome-д зөвшөөрнө.
  3. «Суулгах» → Aura-г нээж бүртгүүлнэ.

Android 7.0 ба түүнээс дээш. Шинэ хувилбар суулгахад өмнөхийн өгөгдөл хадгалагдана.

APK хараахан build хийгдээгүй байна. DEV машин дээр: docker compose --profile devbuild run --rm expo-dev apk

iPhone — Expo Go

{{QR_EXPO}}
  1. App Store-оос Expo Go-г суулгана.
  2. iPhone-ийн камераар энэ QR-ыг уншуулж «Expo Go-д нээх»-ийг дарна.
  3. Эсвэл Expo Go → «Enter URL manually»: {{EXPO_URL}}

Android дээр ч Expo Go-оор нээж болно (Expo Go апп доторх «Scan QR code»).

Вэб апп (PWA)

{{QR_PWA}}

{{PWA_URL}}

iPhone (Safari):

  1. Хаягийг Safari-гаар нээнэ.
  2. Доод талын «Хуваалцах» товч → «Нүүр дэлгэцэнд нэмэх» → «Нэмэх».
  3. Нүүр дэлгэц дээрх Aura дүрсээр нээнэ.

Android (Chrome):

  1. Хаягийг Chrome-оор нээнэ.
  2. Баруун дээд ⋮ цэс → «Апп суулгах» (эсвэл «Нүүр дэлгэцэнд нэмэх»).

Анхаарах

  • Утас энэ компьютертэй нэг Wi-Fi сүлжээнд байх ёстой.
  • DEV хаяг нь http тул мэдэгдэл (Web Push), Google нэвтрэлт, passkey вэб апп-д ажиллахгүй — эдгээрийг prod-ийн HTTPS хаяг дээр шалгана.
  • Энэ хуудас ба APK зөвхөн туршилтад — бусдад бүү түгээ.
